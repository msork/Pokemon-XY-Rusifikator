# Repository and Contribution Workflow

Primary repository: https://git.gay/msork/Pokemon-XY-Rusifikator

GitHub mirror, synchronized externally by git.gay: https://github.com/msork/Pokemon-XY-Rusifikator. Configure `origin` to the git.gay URL. Push only completed, tested milestones to that remote after checking its current history. Never force-push or push directly to GitHub.

Contributors should use a topic branch and the git.gay review workflow. Keep all developer communication in English. Do not include game dumps, extracted assets, saves, generated full copyrighted binaries, secrets, or unlicensed third-party files. See [licensing](licensing.md) for scope and [README](../../README.md) for local validation commands.
