## Contributing

Use a topic branch and submit changes through the primary git.gay repository's supported review workflow. The GitHub repository is an externally managed mirror and must not receive direct pushes. Write developer-facing material in English. Keep source assets and secrets out of changes. Include automated test commands and results for tooling changes, document evidence and limitations, and do not claim emulator behavior without a recorded AzaharPlus 2126.2-A test.
