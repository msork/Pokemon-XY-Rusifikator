## Milestone 2B Russian rendering proof

The uninstalled test patches are generated by `python scripts/build_russian_poc.py` at:

- X: `build/milestone-2b/pokemon-x/0004000000055D00/romfs/a/0/7/4`
- Y: `build/milestone-2b/pokemon-y/0004000000055E00/romfs/a/0/7/4`

Each replaces update-only `Ver. 1.5` in GARC member 35/0, message 22 with a Russian greeting. The patch is built from the update 1.5 archive. Azahar's 2126.2 loader source maps update program IDs to the base game Title ID when resolving the LayeredFS directory, so use the two base IDs above. This is source-based path evidence; confirm it against the local X/Y logs.

Do not copy the test patch until ready to run the test. Run the unmodified game first and note the v1.5 marker. Close AzaharPlus before changing mod files. For X, in PowerShell from the project root:

```powershell
$source = (Resolve-Path '.\build\milestone-2b\pokemon-x\0004000000055D00\romfs\a\0\7\4').Path
$romfs = Join-Path $env:APPDATA 'AzaharPlus\load\mods\0004000000055D00\romfs'
$target = Join-Path $romfs 'a\0\7\4'
if (Test-Path -LiteralPath $target) { throw 'A file already exists at the test target. Back it up and review the conflict before proceeding.' }
New-Item -ItemType Directory -Force -Path (Split-Path -Parent $target) | Out-Null
Copy-Item -LiteralPath $source -Destination $target
```

For Y, use source `build\milestone-2b\pokemon-y\0004000000055E00\romfs\a\0\7\4` and change the mod Title ID in `$romfs` to `0004000000055E00`. Do not copy a whole generated `romfs` tree over an existing mod; install only the one resource file. If another mod already provides this target, back it up and resolve the conflict manually before testing.

Launch the corresponding game with update 1.5 active. Check whether the title/save menu shows the Russian marker and whether the Cyrillic glyphs are correct, substituted, or missing. To remove the proof after the run, close AzaharPlus and remove only the exact `romfs\a\0\7\4` file if it is the POC file copied above. Restore any backup made before the test.
