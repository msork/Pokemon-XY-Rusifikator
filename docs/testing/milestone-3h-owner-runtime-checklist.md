## Pokémon X

1. Start a new game only if an existing safe test profile is available; do not overwrite a valued save. On character naming, inspect the prompt, visible key labels, punctuation/page controls, and accepted characters. Do not expect the current candidate set to change the keyboard.
2. At the nickname proposal, check the choices corresponding to `Li’l B`, `Lady B`, `B-kins`, and `Pick your own`; note awkward agreement, spacing, clipped text, or literal control placeholders.
3. During starter selection, verify the displayed names for Chespin, Fennekin, and Froakie. Candidate Russian names are Чеспин, Феннекин, and Фроки, but they remain drafts until installed/tested.
4. In the first battle, record the chosen starter's name and the opponent's name before and after the species is registered/identified. This distinguishes an unknown-opponent marker from a Cyrillic-name rendering failure.
5. Inspect the battle command buttons, ally/enemy gauge labels, move names, PP, and type labels. The TextFile candidates are not installed; only the battle button and gauge labels require image edits.
6. At the Prof’s Letter acquisition, check player-name spacing, line break, item color, item-name substitution, and punctuation.

## Pokémon Y

## Report format

For each result provide game/version, screen/scene, visible text exactly, screenshot filename, chosen protagonist, starter, battle opponent, and whether the species was already registered. Do not edit saves or settings for this test.
